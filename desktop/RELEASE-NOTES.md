Download **BLACKROOT-Setup-0.9.0-x64.exe**, open it, and follow the installer.
Launch BLACKROOT from the desktop shortcut or Start menu.

- Windows 10 / 11, 64-bit Intel / AMD PCs.
- Complete game included; single-player works offline.
- BLACKROOT ONLINE includes public multiplayer matchmaking through the hosted BLACKROOT server.
- Choose **BLACKROOT ONLINE / CO-OP** → **JOIN PUBLIC ONLINE** to automatically join an available public session.
- Private multiplayer remains available with six-character invite codes.
- Keyboard / mouse and the game's existing Xbox / PlayStation controller support.
- Press F11 to toggle fullscreen; Esc pauses the game.
- Saves and settings are stored locally and preserved when uninstalling.
- Remove the game through Windows Settings → Apps → BLACKROOT → Uninstall.

The production multiplayer endpoint is configured automatically in the game; players do not need to enter a server address for public matchmaking.

This is an unsigned early release. Windows may display an unknown publisher notice. Download only from the official BLACKROOT GitHub repository.

The attached test report records the automatic Windows installation and gameplay smoke test. Hardware performance and physical controllers have not been tested on every PC.
