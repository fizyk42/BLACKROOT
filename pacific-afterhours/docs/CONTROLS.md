# Controls

Every binding below can be changed in **Pause → Controls**. Click a binding, press the
new key, and it saves immediately. Press Escape while it is listening to cancel.

## On foot

| Action | Keyboard / mouse | Controller |
|---|---|---|
| Move | `W` `A` `S` `D` | Left stick |
| Look | Mouse | Right stick |
| Sprint | `Shift` (hold) | Left stick click |
| Jump | `Space` | A / Cross |
| Crouch | `Ctrl` or `C` | X / Square |
| Interact, enter vehicle | `E` | Y / Triangle |
| Aim | Right mouse button | Left trigger |
| Fire / melee | Left mouse button | Right trigger |
| Reload | `R` | — |
| Next weapon | `Q` | LB / L1 |
| Holster | `X` | B / Circle |
| Change camera | `V` | D-pad down |
| Zoom camera | Mouse wheel | — |

## Driving

| Action | Keyboard / mouse | Controller |
|---|---|---|
| Throttle | `W` | Right trigger (analogue) |
| Brake / reverse | `S` | Left trigger (analogue) |
| Steer | `A` `D` | Left stick |
| Handbrake | `Space` | A / Cross |
| Horn | `H` | — |
| Headlights | `L` | — |
| Recover a stuck vehicle | Hold `U` | — |
| Get out | `E` | Y / Triangle |
| Change camera | `V` | D-pad down |

Cameras cycle through chase, close chase, bonnet and wide.

## Interface

| Action | Keyboard | Controller |
|---|---|---|
| Pause / back | `Escape` | Menu / Options |
| Map | `M` | D-pad up |
| Mission journal | `J` | D-pad left |
| Progress and stats | `T` | D-pad right |
| Show players (online) | `Tab` | View / Share |

Controller glyphs switch between Xbox and PlayStation automatically based on the pad
that is connected. You can force one in **Pause → Settings → Controller glyphs**.

## Notes

- The mouse needs to be locked to the page for looking around to work. Click the game
  once if you have clicked away. Escape releases it.
- Analogue triggers give proportional throttle and braking, which makes drifting much
  easier to control than the keyboard.
- Stick deadzone, mouse sensitivity, controller sensitivity and vertical inversion are
  all in **Pause → Settings**.
- Hold-to-sprint can be switched to toggle-to-sprint in the accessibility section.
