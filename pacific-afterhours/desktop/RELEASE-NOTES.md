Pacific Afterhours 0.3.2 — Windows playable alpha

Download Pacific-Afterhours-Setup-0.3.2-x64.exe, run the installer, then launch Pacific Afterhours from your desktop or Start menu. Windows 10/11 x64 and WebGL 2 capable graphics are required. The installer is unsigned.

Includes offline Story Mode (three playable missions), Free Roam, driving, freelance jobs, races, police, local saves, graphics settings, and Xbox/PlayStation gameplay controls. Menus, shops, pause screens and settings support controllers. Connect a PS5 DualSense, PS4 DualShock 4 or Xbox controller by USB or Bluetooth and press a button. Standard browser gamepad mapping is required. Text entry and keyboard rebinding use a keyboard. The rest of the planned story is not implemented. Online play requires a separately hosted compatible multiplayer server; enter its WebSocket address in the Online menu.

Controller changes include menu navigation, correct trigger press detection, reloading, vehicle horn/headlights/recovery, button labels, disconnect pausing and frame-rate-independent camera controls. Automated virtual-controller checks cover the input logic and installed menu flow; physical controllers were not available for testing.

The installation and automated city-render check run on a Windows runner before this release is published. See game-test-report.json and SHA256SUMS.txt. This is not a full manual gameplay or performance certification.

This game is stored in the pacific-afterhours folder of this repository. BLACKROOT is a separate game.
